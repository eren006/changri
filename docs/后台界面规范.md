# 后台界面规范

做控制台（`admin/templates/`）的新页面或改旧页面时照这份来。样式全部在 `base.html` 里，页面内容包在 `<div class="ui">` 中，**不要再给单个页面写一份自己的 `<style>`**（只有确实独有的布局才允许，且要用 `.ui` 里的颜色变量）。

## 一、原则

1. **列表在前，表单收起来。** 进页面先看到数据；新建、批量导入、发放这类操作是一个按钮，点开才出现表单（`details.panel`），保存或取消后收回去。
2. **一页一件事。** 物品与商城、属性、地点是三个页面，别塞进一页。像「短信」和「私约」这样不同性质的内容用标签页分开，不要混排。
3. **手机优先。** 断点 720px：点击目标 ≥44px，输入框 16px（防 iOS 缩放），表格自动变卡片。
4. **用颜色变量，不写死色值。** 见下。
5. **文案用人话。** 按钮写动作（「保存地点」「生成认群码」），错误说清楚怎么办，空状态给出下一步。

## 二、颜色与字体

变量：`--paper`（页底）`--surface`（卡片/表单底）`--ink`（正文）`--mute`（次要文字）`--line`（边线）`--soft`（浅底）`--dusk`（强调）`--ok` `--warn` `--bad`（状态）。标题用衬线（`h1/h2`），正文无衬线。

## 三、组件清单

### 页头
```html
<h1>标题</h1>
<p class="lede">一两句话说明这页是干什么的。</p>
```

### 区块头 `.sec-head`
左边标题（可带 `<span class="n">12 项</span>` 计数），右边放 `.btns`。

```html
<div class="sec-head"><h2>地点<span class="n">{{ places|length }} 处</span></h2>
  <span class="btns"> …面板按钮… </span></div>
```

### 折叠面板 `details.panel`（表单的标准写法）
```html
{% import "_rpg_icons.html" as ic %}
<span class="btns"><details class="panel"><summary class="btn">{{ ic.plus() }}新建地点</summary>
  <form class="form" method="post" action="…">{{ csrf() }}
    <div class="fields">
      <div><label for="x">名称</label><input id="x" name="name" required></div>
      <div><label class="check"><span class="sw"><input type="checkbox" name="on"><i></i></span>开关文字</label></div>
    </div>
    <p class="note">一句补充说明。</p>
    <div class="actions"><button class="btn" type="submit">保存</button>
      <button class="btn ghost" type="button" onclick="this.closest('details').open=false">取消</button></div>
  </form></details></span>
```
- 主操作用 `summary.btn`，次要（批量导入、发放）用 `summary.btn.ghost`。
- 打开后面板自动占满整行（不会被挤在窄列里），按钮被面板替代。
- 图标在 `_rpg_icons.html`：`plus` `tray` `sliders` 等；要新图标就在那里加一个宏，别散落在页面里。

### 标签与状态
- `.chip`：小标签（如「体力 +20」）。
- `.kind`：类别标记（物品/货币…）。
- `<span class="dot ok|warn|bad"></span>文字`：状态点。
- `.note`：灰色小字说明；`.empty`：空状态。

### 列表
- 简单列表：`.rowlist > .row`。
- 多列数据：`<table class="rt">`，外面包 `<div class="tablewrap">`。手机上每行自动变卡片，列名取自 `<th>` 文字（base.html 里的 JS 会写入 `data-label`），所以**每个 `<th>` 都要写文字**，操作列的 `<th>` 留空即可。
- 需要更精细的手机卡片（头部放名称、右上放编辑）时用 `table.cards`，参考 `rpg.html`。

### 状态卡片、提示、行内操作
- `.stats > .stat`：一排状态小卡片（`<b>` 是大字，`<span>` 是说明），季度页顶部用它。
- `.callout`（黄）/ `.callout.bad`（红）：需要注意的提示条。
- `.queue > .q`：带序号的胶囊队列（出场顺序）；`.pair`：「甲⇄乙」这种成对名字。
- `.sec-head.keep`：标题和右边按钮手机上也保持同一行（不加 keep 的，手机上按钮会掉到标题下面整行显示）。
- `.acts`：一行里的一组操作（小按钮 + 面板按钮），放在 `.rowlist > .row` 右边；面板展开后自动占满整行。
- 行里的小字说明用 `.muted`，状态用 `.kind` / `.dot`；整页的行都是「标题 + 一行灰色摘要 + 右边操作」。

### 危险操作
删除/移除用 `linkbtn`，必须带 `onsubmit="return confirm('…说清楚会删什么、能不能撤销')"`。不要做成醒目的大红按钮。

## 四、写页面的步骤

1. `{% extends "base.html" %}`，设 `title`，`body` 里写内容（已经在 `.ui` 里）。
2. 先 `h1` + `lede`，再按「一个 `section` = 一个 `sec-head` + 列表 + 面板按钮」往下排。
3. 所有写操作都用 `<form method="post">` 加 `{{ csrf() }}`，链接用 `url_for(...)`（多机器人前缀才会正确）。
4. 新页面如果属于可开关的扩展：在 `core/extensions.py` 的 `OFFICIAL` 里登记，`admin/__init__.py` 的 `guard()` 里加页面前缀，侧栏会自动放进「额外」。
5. 用 `tests/test_admin_multibot.py` 的写法加一条能打开页面、能保存的测试。

## 五、自查清单

- [ ] 375px 宽打开，没有横向滚动，按钮好点。
- [ ] 没有裸 `<table>`（都有 `rt`/`cards`）、没有内联 `style` 写颜色。
- [ ] 表单默认是收起的，打开后占满一行。
- [ ] 删除有确认；空状态有提示。
- [ ] 深浅两种情况下文字都读得清（只用变量就不会错）。
