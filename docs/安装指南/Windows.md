# 在 Windows 上安装长日bot

适用：Windows 10 / 11 / Server 2016 以上，64 位。

## 1. 下载解压

1. 从 https://system.changri.work/install 下载 Windows 版 zip。
2. **先解除锁定**：右键 zip →「属性」→ 勾选最下面的「解除锁定」→ 确定。从网上下载的文件会被 Windows 标成「来自 Internet」，不解除的话，双击启动时会弹安全提示（在远程桌面里常被挡在后面，看起来像没反应）。
3. 解压到一个固定的位置，例如 `D:\changri-bot`（路径里最好不要有空格）。解压完 zip 就可以删了。

## 2. 启动

双击 `Start-Changri.bat`。如果弹出「打开文件 - 安全警告」，点「运行」；弹出蓝色的「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。会弹出一个黑色窗口，第一次会自动打开浏览器进入设置平台，跟着安装向导走。

窗口开着，机器人就在运行；关掉窗口就停止。

> 有的杀毒软件会对 .bat 弹提示：这些都是普通的文本脚本，可以右键「编辑」用记事本看内容。

## 3. 开机自动运行（服务器上建议做）

1. 先关掉 `Start-Changri.bat` 的窗口（否则端口会冲突）。
2. 右键 `Install-Autostart.bat` →「以管理员身份运行」。

之后开机会在后台自动运行，不需要有人登录，也没有窗口。它还会在 Windows 防火墙里放行 5091、5092。

取消：右键 `Remove-Autostart.bat` →「以管理员身份运行」（数据不动）。

## 4. 云服务器要放行端口

到云服务商网页控制台，给这台服务器的「安全组」放行 TCP 5091（设置平台）和 5092（小手机，默认开着）。

## 其他

| 文件 | 用途 |
|---|---|
| `Doctor.bat` | 自检：端口、能不能连上 QQ、公网 IP。不知道哪里不对时先运行它 |
| `Install-HTTPS.bat` | 想开 HTTPS 时，以管理员身份运行装 Caddy，装好后回设置平台「HTTPS」页点「开通」 |
| `data` 文件夹 | 所有数据。备份 = 复制这个文件夹 |

升级：在设置平台「更新」页一键升级，不用重新下载。会先备份；新版本起不来会自动退回旧版本。
