# 从老版本（0.19 及以前）迁移到新安装包

老版本是「一个目录里放 bot.py、data/、.env、venv/」，靠系统里装的 Python 运行。新版本自带运行环境，目录结构也不一样，所以要装一次新的，再把数据搬过来。**老目录不会被改动或删除**，确认新版本没问题后再自己删。

## Linux

直接运行一键安装，它会自动处理：

```bash
curl -fsSL https://system.changri.work/get.sh | sudo sh
```

- 发现 `/opt/changri-bot` 是老版本：先 `systemctl stop changri-bot`，把老目录改名为 `/opt/changri-bot.old-时间`；
- 装新版本，然后运行 `changri migrate-legacy` 把老目录里的 `data/`、用户扩展、`.env` 里的端口设置搬过来；
- 设为开机自启并启动（服务名还是 `changri-bot`，会覆盖老的服务配置）。

老版本装在别的目录的：先 `sudo systemctl stop changri-bot`，装好新版本后手动搬：

```bash
sudo systemctl stop changri-bot
sudo /opt/changri-bot/changri migrate-legacy /老版本/的/目录
sudo chown -R changri: /opt/changri-bot/data
sudo systemctl start changri-bot
```

## Windows

1. 关掉老版本的窗口；设过开机自启的，以管理员身份运行老目录里的命令：`schtasks /Delete /TN ChangriBot /F`。
2. 下载解压新版本（见 [Windows.md](Windows.md)），**先不要启动**。
3. 在新目录打开命令提示符，运行（把路径换成老目录）：

   ```bat
   call _env.bat
   "%PY%" -m changri migrate-legacy D:\老的长日bot目录
   ```

   或者手动：把老目录的 `data` 文件夹整个复制到新目录里，`.env` 里改过端口的，到新目录 `data\config.toml` 里改 `port`。
4. 双击 `Start-Changri.bat`，确认能登录、数据都在，再按需要设开机自启。

## 迁移后有什么不一样

- 小手机：所有机器人共用一个端口（默认用第一个开着小手机的机器人原来的端口）。其他机器人发给玩家的网址里的端口会自动改掉；玩家要重新打开新网址，激活码不变。安全组只需要放行这一个端口。
- 配置：`.env` 换成了 `data/config.toml`（只剩监听地址、端口、日志级别）。
- 用户扩展：从程序目录的 `extensions/` 挪到了 `data/extensions/`。
