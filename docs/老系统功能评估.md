# 老长日系统（SealDice 版）还没搬到长日bot 的功能清单

整理于 2026-11-14。对比方法：老系统 11 个脚本里一共注册了约 207 条指令（另有漂流瓶、混乱寄信这类不靠指令名触发的玩法），逐条看它的说明文字，和长日bot 现有功能对照。

**怎么选：** 每项有编号。直接回「做 3、5、12」或「A 组全做、D 组不要」都行。「建议」一栏是我的判断：

- **做**：玩家或运营会经常用，值得搬
- **可选**：有用，但看你的节目用不用得到
- **不做**：调试/维护用，或新架构里没有意义
- **已有**：长日bot 里已经有了，不用再搬

「工作量」：小 = 半小时内，中 = 一两小时，大 = 要先写设计。

## F. 明确不搬的（调试/维护用，或新架构里没意义）

你说过有些是之前调试用的，我按这个标准挑了一批：

| 功能 | 为什么不搬 |
|---|---|
| 约会数据体检、更新未退群、人工登记、维护工具说明、清除玩家 | 老系统自己标着「维护工具·请勿随意使用」，用来修老架构里多份存储不一致的数据。长日bot 只有一个数据库，不会出现这类问题 |

## 我的建议顺序

1. **先做 A 组 4 项**（你已经点名）。
2. **再做 B1、B2、B6、C1**：功能权限、时间线管理、关系线/帖子管理、漂流瓶。都是运营或玩家会马上用到的。
3. **其余看你的节目要不要**：写信综（C2）、抽取池（D1）、小游戏（E 组）、前置电话（C5）各是一整块，建议你挑一两块先做，别一次全上。
4. **战斗和装备（D6、D7）先不做**，除非你确认有人在用。

## 没算进来的

- 我只统计了老系统里「注册成指令」的功能，加上能确认的玩法（漂流瓶、混乱寄信、踩点）。如果有你记得的玩法不在这份清单里，告诉我，我再去老代码里找。
