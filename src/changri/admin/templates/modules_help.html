长期群{{ status(mods.longterm) }}

恋综、跑团之外的第三种群模式，给长期开着、不分季度的群用：没有时间线和房间，大家写戏、聊天，按写了多少字换货币，再拿货币买东西、合成、做检定。

适合
长期的写手群、陪伴群、养成类的群；想按字数发奖励、又不想开一季恋综的。
怎么开始
后台「长期群」页建一个长期群（可以建好几个），QQ 群里管理员发 /模式 长期群、/切换长期群 名字。之后群里发 /长期群帮助 能看到全部指令。
玩家做什么
先发 /注册 名字；写完的戏合并转发到群里，回复它发 /字数统计 交字数（默认要管理员在后台批准才入账）；/签到、/商城、/赠送、/合成；/ra /rt 读自己的属性面板。；/写条目 魔杖 木材：冬青 给自己记一栏一栏的设定，像备忘录，都不是必填，/条目 查看。
管理员做什么
后台定货币和「多少字换多少」、属性、道具和价格、签到奖励、KPI；在「总览」批准字数、看所有人的动态；群里 /调整、/发放 直接加减。
跟恋综的关系
数据完全分开：角色、货币、道具都不通用。切到长期群模式的群里，恋综指令不响应。
{{ acts(mods.longterm, "打开长期群") }}

排单{{ status(mods.paidan) }}

给接稿的人（下面叫 owner）管理订单：客户在群里按格式下单、补图，机器人登记单号、转到对应的工作群，算额度和单口，每天提醒到期和工期。

适合
接画稿、修图、手工这类按「张」卖的人，有好几种业务、好几个客户群。
几个词
业务：一种服务（A、B、C），各有工作群、工期、默认单口；额度：客户买的一笔张数和到期日；单口：同一客户同一业务最多同时几单；散单：没有客户档案的人凭兑换码下单。
怎么开始
后台「排单」页建业务、生成绑定码；在工作群、客户群、散单群里发 绑定 绑定码；owner 本人也绑一次。
客户做什么
下单（照格式填）、补充 单号 …、已上传所有图 单号、我的额度。
owner 做什么
在工作群回复成品图 发送 单号 交付，再到网页上扣张数；可以按天暂停，工期自动顺延。
{{ acts(mods.paidan, "打开排单") }}

写信综{{ status(mods.letters) }}

恋综里的正式信件玩法：比短信正式、比心动信公开，按字数给写信币赏金，还有偷看和截信的道具。

适合
想让玩家多写长篇书信、制造信件戏剧性的恋综季。
玩家做什么
在个人群发 发送信件，写【收件人】【内容】，可选【日期】【附件】【署名】，收件人在个人群收到（太长时画成信纸）。信件状态 看今天还能寄几封、写信币多少。
道具
「望远镜」抄一份某人寄出的下一封信；「羽毛笔」把某人的下一封信截到自己手里，羽毛笔修改 改完照常寄出。写信币和两个道具第一次用到时自动建好。
设置
每天封数、冷却、写信币赏金在「功能与设置」的「写信综」组里。没有单独的后台页面。收尾时信件清空。
{{ acts(mods.letters, "") }}

故事历{{ status(mods.storycal) }}

让恋综的「天」对上故事里的日期：把现实里的一天（D）平分成若干故事日，比如 D0 = 康熙十四年 3月1日–3月31日。

适合
古风、年代、跨度很长的剧情：现实一天要演完故事里的一个月。
打开以后
换天公告、季度状态会带上故事日期；开房间时写故事里的某一天（比如「3月5日」），不再写钟点。
不变的
心动信、每日上限、自动换天照旧按 D 和现实时间走。
设置
后台「故事历」页定每个 D 对应的故事日期范围。
{{ acts(mods.storycal, "故事历设置") }}
