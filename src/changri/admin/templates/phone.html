怎么放行端口 {{ port }}

这一步只有你能做：到云服务器的网页控制台，给这台服务器的「安全组 / 防火墙」添加一条入站规则，协议 TCP，端口 {{ port }}，来源 0.0.0.0/0。

  • 腾讯云：控制台 → 云服务器 → 点你的服务器 → 安全组 → 编辑规则 → 入站规则 → 添加规则
  • 阿里云：控制台 → 云服务器 ECS → 实例 → 安全组 → 配置规则 → 入方向 → 手动添加
  • 华为云：控制台 → 弹性云服务器 → 安全组 → 配置规则 → 入方向规则 → 添加规则
