{# 把服务器公网 IP 加进 QQ 开放平台白名单的分步教程：安装向导、「机器人接入」页都用这一份。 按钮名照 QQ 开放平台现在的界面写（2026-11 作者核对过）；界面改了就改这里，再改 core/botconf.py 的 WHITELIST_PATH。 #} {% macro ip_whitelist_steps(ip) %}
  1. 打开 QQ 开放平台 q.qq.com，用创建机器人的那个 QQ 登录。
  2. 点「机器人」，再点蓝色的「去创建或管理我的 QQ 机器人」。
  3. 在列表里点你要用的那个机器人。
  4. 点「开发设置」。
  5. 往下找到「服务器 IP 白名单」，点右边的「＋ 添加 IP」，填这台服务器的公网 IP，保存： {% if ip %}{{ ip }} {% else %}（这里没能自动查到。在服务器上用浏览器打开 ip.cn 或搜「IP」，看到的那串数字就是）{% endif %}

要填的是 IP（一串数字，像 1.2.3.4），不要带 http:// 和端口。以后服务器换了 IP（换云服务器、重装、家里宽带重新拨号），要回来再加一次新的。
