{# 在云服务商的安全组里放行一个端口的分步教程：安装向导、小手机页都用这一份。 先选是哪家云（阿里云 / 腾讯云 / 别的），只显示那家的步骤。阿里云 ECS、腾讯云轻量应用服务器按 2026-11 的控制台写（作者照截图核对过）；腾讯云 CVM、华为云暂时只有路径，界面核对过再补成分步。 #} {# admin_port = 设置平台端口（默认 5091），phone_port = 小手机端口（默认 5092）：两个都要放行，在一条规则里填。 #} {% macro open_port_steps(admin_port, phone_port) %} {% set adj = phone_port == admin_port + 1 %}

机器人装在云服务器上的话，要在云服务器的「安全组」里放行两个端口：{{ admin_port }}（这个设置平台，你在外面才打得开）和 {{ phone_port }}（小手机，玩家要用）。这一步只能在云服务商的网页控制台里做。

你的服务器是哪家的？选一下，下面出对应的步骤：

适用于阿里云「云服务器 ECS」。

  1. 打开阿里云控制台，在「计算」下面点「云服务器 ECS」。
  2. 在实例列表里点你装机器人的那台服务器，进到它的详情页。
  3. 点上方的「网络与安全组」标签。
  4. 在安全组规则的「入方向」里，点「＋ 添加入方向规则」。
  5. 弹出的窗口照下面填：
    授权策略允许（默认就是，不用动）
    优先级1（不用动）
    协议类型选「自定义 TCP」
    访问来源左边保持 IPv4，右边填 0.0.0.0/0（意思是任何地方都能访问，玩家在哪儿都能打开）
    访问目的左边保持「端口」。如果里面已经有 HTTP(80) 之类的，先点 × 删掉。右边输入 {{ admin_port }} 按回车，再输入 {{ phone_port }} 按回车，两个都要有。{% if adj %}要是它只认范围写法，就填 {{ admin_port }}/{{ phone_port }}（一次放行这两个）。{% else %}要是它只认范围写法，就分两条规则添加，一条填 {{ admin_port }}/{{ admin_port }}，一条填 {{ phone_port }}/{{ phone_port }}。{% endif %}
    描述选填，写「长日 设置平台+小手机」方便以后认
    最后点「确定」。

适用于腾讯云「轻量应用服务器」。买的是「云服务器 CVM」的，选「别的」。

  1. 打开腾讯云控制台，点「轻量应用服务器」。
  2. 直接点你那台服务器的方块（点名字那块就行，不要点右边的「登录」）。
  3. 点上方的「防火墙」标签。
  4. 点蓝色的「添加规则」。
  5. 弹出的窗口照下面填：
    应用类型自定义（默认就是，不用动）
    来源填 0.0.0.0/0（空着也一样，默认就是所有地方都能访问）
    协议TCP（默认就是）
    端口填 {{ admin_port }},{{ phone_port }}（两个端口用英文逗号隔开，一条规则就够）
    策略允许（默认就是）
    备注选填，写「长日 设置平台+小手机」方便以后认
    最后点「确定」。
  • 腾讯云云服务器 CVM：控制台 → 云服务器 → 点你的服务器 → 安全组 → 编辑规则 → 入站规则 → 添加规则
  • 华为云：控制台 → 弹性云服务器 → 安全组 → 配置规则 → 入方向规则 → 添加规则

规则内容都一样：协议 TCP，端口 {{ admin_port }} 和 {{ phone_port }}，来源 0.0.0.0/0。
