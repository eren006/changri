# 长日bot

一个独立的 QQ 官方机器人，用来跑「长日将尽」这类群恋综：角色、短信礼物、私约、心动信、关系线、论坛、季度，外加一部给玩家用的网页小手机。装好以后在网页后台管理，不用改代码。

一个机器人就是一套独立的系统，一台服务器上可以同时接好几个机器人，各管各的数据。

## 你需要准备

1. **一台服务器**：Linux（Ubuntu/Debian/CentOS 都行）或 Windows，能访问外网，有公网 IP。2 核 2G 内存够用。
2. **一个 QQ 官方机器人**：在 QQ 开放平台（q.qq.com）创建，拿到 **AppID** 和 **AppSecret**。
3. 不需要域名，不需要备案。

## 安装

**Linux 一条命令**（会自己装 git、Python、依赖，并设成开机自启）。用腾讯云「登录」按钮打开网页终端，粘贴这一行回车：

```bash
curl -fsSL https://raw.githubusercontent.com/eren006/changri/main/get.sh | sudo bash
```

已经有压缩包的话，解压后在目录里运行 `sudo ./install.sh` 也一样。重复运行是安全的，不会动已有数据。

**Windows**：双击 `start.bat` 先试跑；想开机自动运行，右键 `install_autostart.bat` 选「以管理员身份运行」。

装完屏幕上会打印：设置平台的网址、小手机的网址、**首次设置验证码**。记下来。

> 云服务商的「安全组」（腾讯云轻量服务器里叫「防火墙」）要手动放行端口，程序碰不到这一步：放行 **5091**（设置平台）和 **5092**（小手机，后面开启才用）。

## 第一次使用：跟着向导走

1. 浏览器打开 `http://服务器公网IP:5091`。
2. 输入安装时打印的验证码，创建你的管理账号（密码至少 8 位）。
3. 会自动进入**安装向导**，五步：
   - **接入机器人**：填 AppID 和 AppSecret。
   - **让机器人连上**：QQ 要求把服务器公网 IP 加进白名单（开放平台 → 开发管理 → 开发设置 → IP 白名单），向导会告诉你该填哪个 IP，加好后点「检查连接」。
   - **设一位 QQ 管理员**：在后台生成管理员码，在群里发 `认管理员 码`。
   - **建第一个角色**：玩家在自己的个人群里发 `创建新角色 名字`。
   - **开启小手机**（可选）：玩家用激活码在网页里发短信、送礼。

每一步做完会自动打勾，做到一半离开也没关系，回来接着做。向导随时可以从左侧「安装向导」再打开。

## 同时接多个机器人

后台登录后先看到「选择机器人」。在「机器人接入」里再添一个，就多一套独立的系统：角色、季度、群、设置、小手机都是各自的，互不影响。

- 每个机器人的小手机用各自的端口（5092、5093、5094……），在它自己的「小手机」页开启时程序会建议一个没被占用的端口。每多开一个端口，云安全组也要放行一次。
- 「移除」只是不再接收消息，数据保留，用同一个 AppID 重新添加就回来了。
- 「彻底删除」会删掉这个机器人的全部数据，不能撤销，需要输入 AppID 确认。

## 日常使用

| 想做的事 | 在哪里 |
|---|---|
| 管理角色、群、季度、心动信、论坛、群池 | 后台各页面 |
| 开关功能、调规则（开放时段、每日上限、公开播报……） | 后台「功能与设置」 |
| 让玩家用网页小手机 | 后台「小手机」页开启，玩家在个人群发「手机码」拿激活码 |
| 只允许自己的 IP 打开后台 | 后台「远程访问」 |
| 升级到新版本 | 后台「更新」，会先自动备份，更新包有签名校验 |
| 加新功能 | 后台「功能与设置」里装扩展，写法见 `docs/写扩展.md` |

## 安全提醒

- 后台默认就能用「公网 IP:5091」打开，是 http 明文。登录有逐级锁定（输错越多锁得越久），首次设置要验证码。想更稳妥，可以只在「远程访问」页放行自己的 IP，或在 `.env` 里把 `HOST` 改成 `127.0.0.1` 只在本机打开。
- 小手机的激活码很长，登录也有限速，但同样是明文 http。页面上没有任何密码。
- **扩展是 Python 代码，装上就有和主程序一样的权限**，只装信得过的人写的。
- 数据都在 `data/` 目录里（每个机器人一个子文件夹）。备份就是复制这个目录。

## 常见问题

**机器人一直不在线？**
多半是 IP 白名单没加对。进「安装向导」或「机器人接入」点检查连接，它会直接告诉你哪一步没通、该加哪个 IP。

**玩家打不开小手机？**
先在「小手机」页点「检查玩家能不能打开」。没通就是云安全组没放行那个端口。

**想看日志？**
Linux：`journalctl -u changri-bot -f`。Windows：看 `start.bat` 打开的窗口。

**重启？**
Linux：`sudo systemctl restart changri-bot`。Windows：关掉窗口重新双击 `start.bat`。

**升级后出问题？**
更新前会自动备份。如果更新后连续起不来，程序会自动回滚到更新前的版本，数据不会丢。

## 目录说明

```
bot.py              程序入口
core/               规则和数据（短信、房间、心动信、季度……）
plugins/            QQ 里的指令
admin/              网页后台
phone/              玩家的网页小手机
extensions/         你自己装的扩展
data/               数据库（每个机器人 data/bots/<AppID>/）
docs/               设计文档、写扩展说明
tools/              发版、探测服务等工具
```
