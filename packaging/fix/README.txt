长日bot 修复工具（Windows）

长日bot 打不开、设置平台进不去、报错说端口被占用（10048）时用它：

  1. 把这个压缩包解压（放哪里都行）。
  2. 双击 Fix-Changri.bat。
  3. 弹出「是否允许此应用对你的设备进行更改」时点「是」。
  4. 照窗口里的提示做就行。修好后会自动在浏览器里打开设置平台。

它会做什么：
  · 长日bot 正常运行 → 帮你打开设置平台，什么都不改。
  · 长日bot 卡住了 → 把它全部关掉，重新打开。
  · 长日bot 要用的位置被别的软件占了 → 告诉你是哪个软件，问过你才关。
  · 长日bot 没在运行 → 帮你打开。

每次打开会先从官网（@BASE@）取最新的修复办法；连不上就用压缩包里自带的。
如果弹出「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
还是不行的话，把窗口截图发给维护的人。
