长日bot @VERSION@（Windows）

一、第一次使用
  0. （下载 zip 后、解压前）右键 zip →「属性」→ 勾选最下面的「解除锁定」→ 确定。
     没做也没关系：双击启动时如果弹出「打开文件 - 安全警告」点「运行」，弹出「Windows 已保护你的电脑」点「更多信息」→「仍要运行」。
  1. 把整个文件夹放到一个固定的位置，例如 D:\changri-bot（路径里最好不要有空格）。
  2. 双击 Start-Changri.bat。Windows 问「是否允许此应用对你的设备进行更改」时点「是」：
     会自动设成开机自动运行、在后台启动（没有窗口），并在 Windows 防火墙放行端口，然后打开浏览器进入「设置平台」。
     跟着安装向导走：填 QQ 机器人的 AppID 和 AppSecret → 把服务器公网 IP 加进 QQ 开放平台的白名单 → 设管理员 → 建角色。
  3. 之后服务器重启也会自己起来，不需要有人登录。再双击 Start-Changri.bat 只会打开设置平台，不会多开一个。

二、开机自动运行
  第一次双击时点了「否」：机器人就在黑色窗口里运行，关掉窗口就停止，服务器重启后不会自己起来。
  下次双击还会再问；也可以右键 Install-Autostart.bat →「以管理员身份运行」。
  取消开机自启：右键 Remove-Autostart.bat → 以管理员身份运行（之后双击只在窗口里运行，不会再自动装回去）。

三、云服务器要放行端口
  到云服务商的网页控制台，给这台服务器的「安全组 / 防火墙」放行 TCP 端口：
    5091（设置平台）、5092（玩家的小手机，默认开着）

四、其他
  Doctor.bat          自检：端口、能不能连上 QQ、公网 IP。不知道哪里不对时先运行它。
  Reset-Owner-Password.bat  主账号忘了密码时双击：会显示一个新密码，登录后到「账号」页改掉。
  Install-HTTPS.bat   想开 HTTPS 时用（以管理员身份运行），装好后回设置平台「HTTPS」页点「开通」。
  data 文件夹         所有数据都在这里。备份 = 复制这个文件夹。
  升级                在设置平台「更新」页一键更新，不用重新下载这个包。

  下载的 zip 压缩包解压完就可以删掉了。
  有的杀毒软件会对 .bat 文件弹提示：这些都是普通的文本脚本，可以用记事本打开看内容。
