长日bot @VERSION@（Windows）

一、第一次使用
  1. 把整个文件夹放到一个固定的位置，例如 D:\changri-bot（路径里最好不要有空格）。
  2. 双击 Start-Changri.bat。第一次会自动打开浏览器，进入「设置平台」，跟着安装向导走：
     填 QQ 机器人的 AppID 和 AppSecret → 把服务器公网 IP 加进 QQ 开放平台的白名单 → 设管理员 → 建角色。
  3. 黑色窗口开着，机器人就在运行；关掉窗口就停止。

二、开机自动运行（服务器上建议做）
  右键 Install-Autostart.bat →「以管理员身份运行」。之后开机就会在后台运行，不需要有人登录，也不会有窗口。
  先把 Start-Changri.bat 的窗口关掉，否则端口会冲突。取消：右键 Remove-Autostart.bat → 以管理员身份运行。

三、云服务器要放行端口
  到云服务商的网页控制台，给这台服务器的「安全组 / 防火墙」放行 TCP 端口：
    5091（设置平台）、5092（玩家的小手机，开了小手机才需要）

四、其他
  Doctor.bat          自检：端口、能不能连上 QQ、公网 IP。不知道哪里不对时先运行它。
  Install-HTTPS.bat   想开 HTTPS 时用（以管理员身份运行），装好后回设置平台「HTTPS」页点「开通」。
  data 文件夹         所有数据都在这里。备份 = 复制这个文件夹。
  升级                在设置平台「更新」页一键更新，不用重新下载这个包。

  下载的 zip 压缩包解压完就可以删掉了。
  有的杀毒软件会对 .bat 文件弹提示：这些都是普通的文本脚本，可以用记事本打开看内容。
